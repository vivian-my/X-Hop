# Do Language Models Reason Across Languages? 

**X-Hop: Multilingual Multi-Hop Dataset.**
</div>

---

This dataset, i.e., **X-Hop**, extends two English multi-hop question-answering datasets [HotpotQA](https://hotpotqa.github.io/) and [MuSiQue](https://github.com/stonybrooknlp/musique) to four languages: French, Russian, Arabic, and Chinese.
